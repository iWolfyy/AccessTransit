Assignment Overview 
 
In this assignment, your team will design, prototype, test, and implement a mobile solution aligned 
with your assigned topic. Your task is to follow the end-to-end UX design process, incorporating 
Equity, Diversity, and Inclusion (EDI), while producing a high-fidelity prototype and a functional 
mobile solution. You are also required to create promotional and branding materials to position the 
product for investors and the public launch.

Milestone Plan 
Milestone 1: User Research & Analysis + Ideation & Wireframing (LO1, LO2, LO3) 
Research & Analysis 
• 
Define the problem statement and target user group(s), including at least one 
underserved/marginalized segment (ties into EDI later) 
• 
Primary research: user interviews, surveys, or contextual inquiry (Conduct interviews 
with approximately five to eight participants) 
• 
Secondary research: competitor analysis / market scan (3–5 comparable apps) 
• 
Synthesis: affinity diagramming, empathy maps 
• 
Deliverables: 4 user personas, user stories, user journey maps, problem statement and 
"how might we" statements 
Ideation & Wireframing 
• 
Ideation techniques: brainstorming, crazy 8s, or SCAMPER 
• 
Information architecture: sitemap / user flow diagrams 
• 
Low-fidelity wireframes (paper or digital, e.g. Balsamiq/Figma) for key screens 
• 
Deliverable: wireframe set + rationale for chosen flow 
 
Milestone 2: High-Fidelity Prototype + EDI (LO2, LO4) 
• 
Convert wireframes into a clickable hi-fi prototype (Figma etc,) 
• 
Apply visual design system: typography, color palette, spacing, component library 
• 
EDI integration — explicitly document how the design supports:  
o Accessibility (WCAG 2.1/2.2 AA: contrast ratios, text scaling, screen-reader 
labels, touch target sizes) 
o Language/localization considerations 
o Cognitive/motor/visual impairment accommodations 
o Socioeconomic inclusivity (e.g., low-bandwidth mode, offline support) 
• 
Deliverable: interactive prototype + EDI compliance checklist

Milestone 3: User Testing & Iteration (LO5) 
• 
Define test plan: tasks, success metrics, participant count (5+ recommended) 
• 
Testing methods: moderated usability testing, think-aloud protocol, System Usability 
Scale (SUS) survey 
• 
Secure design checks: authentication flow review, data privacy handling, secure storage 
of user data, input validation 
• 
Analyze results: task completion rate, time-on-task, SUS score, qualitative pain points 
• 
Iterate: revise prototype/app based on findings 
• 
Deliverable: test plan, raw results, SUS score, before/after iteration summary 
 
 
Milestone 4: Tech Stack Justification + Mobile App Implementation (LO1, LO4) 
Tech Stack Justification 
• 
Compare 2–3 options (e.g., Flutter, React Native, native Android/iOS, Kotlin 
Multiplatform) 
• 
Justify against criteria: performance, team skillset, accessibility support, dev speed, cost, 
scalability 
• 
Deliverable: short tech stack justification document/table 
Implementation 
• 
Set up architecture (folder structure, state management, navigation) 
• 
Set up Git 
• 
Implement core user flows identified in M1/M2 
• 
Requirements traceability: map implemented features back to requirements (user 
stories/use cases) 
• 
Deliverable: working app build + source code repo + requirements-to-feature traceability 
matrix

Milestone 5: Promotion and Business Pitching (LO6) 
• 
Value proposition canvas and positioning statement 
• 
Go-to-market strategy: target audience, channels, launch plan 
• 
Business model: monetization (freemium, subscription, ads, etc.) 
• 
Emerging UX trends tie-in: how the app leverages or anticipates trends (AI 
personalization, voice UX, AR, etc.) 
• 
Deliverable: pitch deck + short promotional material (poster/video/landing page mockup) 
Professional logo, tagline, and A3 promotional poster; two engaging AI-generated MP4 
videos (one technical demonstration and one business pitch), each 1–2 minutes in 
duration, with clear narration, high-quality visuals, and content tailored to technical 
evaluators, the target audience, and potential investors, demonstrating a strong and 
consistent visual identity 
 
Milestone 6: Individual Contribution and VIVA (all LOs, individually assessed) 
• 
Individual contribution log: what each member did, per milestone, with evidence 
(commits, design files, meeting notes) 
• 
One-page signed individual self-reflection: each student writes and signs a single-page 
reflection covering:  
o Their specific contributions across the milestones 
o Challenges faced and how they were addressed 
o Skills applied or newly learned during the project 
o What they would do differently 
o Handed over directly to the evaluation panel (not submitted as part of the group 
report) 
• 
VIVA prep: be ready to explain any part of the project individually, not just your own 
section. Since Vivas often test whether you understand the whole group's work 
• 
Deliverables:  
o Individual contribution log 
o One-page signed self-reflection (handed to evaluation panel) 
o VIVA attendance/participation 
o Presentation slide deck
